# 📇 React Contact Cards Manager

A simple and beginner-friendly **React Single Page Application (SPA)** for creating and managing digital contact cards. Users can add contact information through a form and view all contacts in a clean card layout.

## 🚀 Project Overview

This project is built using **React**, **JavaScript**, and **CSS**. It allows users to add contact details such as name, job title, phone number, email, and a short description. Once submitted, the contact is displayed as a card on the page.

## ✨ Features

- Add new contacts using a form
- Display contacts as attractive cards
- Search and filter contacts
- Responsive design
- Uses React Functional Components
- State management with React Hooks (`useState`)
- Single Page Application (SPA)

## 🛠️ Technologies Used

- React
- JavaScript (ES6+)
- CSS3
- HTML5
